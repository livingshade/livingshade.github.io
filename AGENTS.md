# Project storage policy

- This project is local-only. Its real project root is `/Users/lbr/Project/livingshade.github.io`.
- Source, authored content, configuration, and essential assets live in this repository.
- Regenerable dependencies, caches, build output, logs, and temporary files should remain outside the repository or be ignored by Git.
- The published site is reproducible directly from the tracked static files; no local dependency installation is required.
